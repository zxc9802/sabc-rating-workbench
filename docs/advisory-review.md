# 八维访谈与报告生成

独立对抗性审查机制已移除。普通访谈仍根据项目事实核对八维信息，主动追问矛盾、风险与缺失依据；不再追加独立审查模型请求，也不要求独立审查通过才展示生成入口。

有待回答的问题时继续显示问题，不能仅因八维已有描述就标记访谈完成或隐藏追问。普通访谈只整理事实和覆盖状态，不生成评分草稿或试点建议。信息完整且没有待回答问题时，只提示“信息已整理完成，现在生成报告吗？”，显示“生成报告 / 继续补充”，不另显示“八维收集完毕”。点击生成后才调用模型输出评分依据和试点建议，再计算、保存报告并打开报告页面。生成期间只显示“正在生成报告…”，不追加访谈、外部检索或独立审查。公司基线确认及证据核验状态不会因此自动改变。

收集完成状态绑定项目、用户回答、公司基线和证据的输入指纹；生成前及保存前均检查资料是否变化，不能使用过期内容生成报告。生成失败保留已收集资料并允许重试。旧版本未保存为报告的评分草稿不会复用，点击后同样重新生成；已保存的历史报告保持不变。

设置 SABC_FAL_API_KEY 后首选 fal GLM，失败重试一次，再使用原提供商的 Luna，最后 DeepSeek。原 SABC_API_KEY 继续供 Luna 使用。密钥仅通过部署环境变量配置。
