# 历史案例回测

当前没有真实历史经营案例，尚未验证决策准确性。本入口比较已确认结构化事实与人工预期等级，不调用模型，也不能代替自然语言理解质量测试。

输入支持报告页导出的单份 JSON 快照，或多个案例组成的 JSON 数组。每个案例包含 project、company、evidence、proposal；也可放在 snapshot 内。可选 expected_grade 为 S/A/B/C/NR，name 为案例名。

```powershell
.\.venv\Scripts\python.exe -m sabc.backtest data\历史案例.json --as-of 2026-09-09 --output data\回测结果.json
```

必须显式指定日期，使证据过期判定可复现。输出包括规则版本、各案例计算结果、重复计算是否一致、人工预期一致率、错误记录。没有人工预期时一致率为空，绝不自动报告100%准确。部分案例格式错误会保留其他结果，并返回非零退出码。

当前规则版本 SABC-2.0.2：被新证据版本替代的旧引用不再提供等级支持，需核对新记录后复评。旧快照可按新规则比较；本工具不会声称重新执行已经退役的旧规则版本。

真实回测建议记录项目当时可见资料、决策日期、人工原评级和后续经营结果。禁止把后续结果泄漏到当时证据中。人工评级一致性和经营结果预测能力应分开分析。
