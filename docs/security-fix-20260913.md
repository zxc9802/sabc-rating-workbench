## 已修复的安全问题

| 问题 | 修复及兼容性处理 |
| --- | --- |
| 普通 SSO 用户收到上游地址及模型路由信息 | 脱敏 bootstrap 配置和模型运行记录；保留原字段结构。密码登录的管理配置界面仍可管理连接。 |
| 更换上游地址时沿用旧密钥 | 以协议、主机和端口绑定连接来源；更换来源必须提供新密钥或显式清除密钥；清除后不再回退到环境密钥。HTTPS 部署下配置接口拒绝 HTTP 上游。 |
| 同步聊天和采集接口绕过任务并发限制 | 同步与后台任务共享实际执行信号量，最多同时执行 2 个；保留同步接口响应格式。 |
| 排队无界、单账号占满资源 | 全局最多 16 个未完成任务、每账号最多 4 个；保留幂等重试与项目任务互斥。自动访谈队列满时仍成功返回已创建的项目，避免重复创建。 |
| 附件取消后仍写入证据 | 写入前在取消操作共用的锁内再次检查取消状态。 |
| 上传解析后才检查大小 | 在 ASGI 接收层限制请求体，包含无 Content-Length 的分块上传；仍接受原有 20 MB 附件上限，另留 multipart 开销。 |
| 登录失败共享一个限流桶 | 按服务端识别的客户端地址分桶，并清理过期记录、限制桶数量。 |
