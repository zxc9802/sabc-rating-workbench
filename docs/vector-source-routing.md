> 当前常规访谈采用 `sabc/dimension_sources.py` 的程序规则，在调用回答模型之前取数；模型的 data_requests 不再触发接口。下文为旧向量实现记录，不参与常规选源。

当前流程：当前问题/上一轮追问及外部缺口 → 八维规则 → 明确的公开地区、产品、仓库参数 → 当天有效证据复用 → 最多两项并行采集 → 一次回答模型调用。查询失败和缺参一并交给回答模型，不当作核验结果。GLM 回答与 DeepSeek 兜底不变。

当前自动模板覆盖市场、政策、价格财报、现金外部条件、替代产品的网络检索，中国风险事项的法律库检索，以及明确 GitHub 地址的开源资源/许可核查。常见产品词和明确“产品/品类/行业：”标签可提取；不能识别或地区冲突时先澄清，不发送整段用户信息。其他接口并非全部自动启用，URL/指标编号型接口需要后续专门规则；百度指数尚未接入。


# 向量选源

常规访谈选源使用 text-embedding-3-large，不再调用 GPT 或 DeepSeek 生成选源计划。GLM 回答及 DeepSeek 回答兜底不变。

## 索引

`sabc/source_vectors.json.gz` 保存接口能力的预计算向量，包括通用渠道、各地方渠道、细分宏观/海外能力以及无需取数样例。公开能力共56条，3072维。不可自动调用的渠道仍有说明，但执行前过滤。索引没有用户或公司资料。

每轮只把问题转换为向量，余弦匹配后校验国家、地区、输入标识、接口可用性。短回复结合前一个问题；普通回复不被历史项目全文的主题主导。排名超过无需取数样例且相似度至少0.25才作为候选。此阈值是当前模型/能力语料的初始验收值，不是通用概率。

参数由明确事实与模板生成，不猜测公司编号、URL或地区。不能构造查询时将所缺条件交给访谈模型继续询问。当天同查询证据默认复用，用户明确要求刷新则重查。通用网页查询要求用户明确给出公开查询要求，并拦截常见敏感字段；不发送整个公司上下文。法律库仅处理明确的中国适用场景，不能用中国法律替代海外规定。

## 配置与更新

- `SABC_EMBEDDING_MODEL`：默认 `text-embedding-3-large`。
- `SABC_EMBEDDING_BASE_URL`：优先独立配置，否则沿用 `SABC_PLANNER_BASE_URL`。
- `SABC_EMBEDDING_API_KEY`：优先独立配置，否则沿用 `SABC_PLANNER_API_KEY`。密钥仅用于服务器端。

能力说明或模型改变后，在已设置上述变量的环境运行 `python -m sabc.vector_sources` 重建索引，再随代码发布。索引的模型/语料指纹不符时拒绝使用，避免静默匹配旧能力。

向量接口失败时不调用聊天模型兜底选源、不执行采集，保留核查缺口并继续访谈。模型调用审计记录向量模型、耗时与成功状态；检索计划记录候选相似度、选中/缺参/已有证据状态。资料正文的BM25/向量检索不在本次改造范围内。
