# 待接入平台的当前依赖

2026-09-09 回访。杭州、广州、深圳、山东已取得有限范围的公开数据，见[多地区接入](local-data.md)。以下平台没有有效业务数据进入证据链，保持未完成；不以目录、首页或其他平台代替。

| 平台 | 已做尝试与证据 | 当前原因 | 下一步与所需输入 |
| --- | --- | --- | --- |
| 国家企业信用信息公示系统 | HTTP默认/直连均521；浏览器ERR_BLOCKED_BY_CLIENT | 网络或客户端拦截，未到企业检索页 | 用户浏览器若可正常访问，可协助解除本工具访问限制；再核验企业查询和验证码 |
| 国家知识产权局数据服务 | HTTP403；浏览器成功进入登录、注册和公开目录 | 注册必须真实姓名、身份证号、地址、邮编、手机短信验证及邮箱 | 已询问用户是否已有账号，建议在浏览器自行登录或实名注册；目录61项和样例不作为本项目专利证据 |
| 北京公共数据开放平台 | HTTP连接失败；浏览器目录成功；路侧车位数据页有下载与API说明；统一认证页可打开 | API明确需要登录后userKey；认证为京通扫码或账号+密码+图形验证码 | 用户在浏览器完成统一身份认证；之后核验文件/API，标识码仅本机加密保存。北京仅是接入验收地区，真实项目按实际地区选择 |
| 上海公共数据开放平台 | 直接HTTP412；浏览器/view/、刷新、根入口均空白 | 本轮4次尝试后停止，未取得实际目录记录 | 访问条件变化后复测，不能把其他地区数据称为上海数据 |

详细请求记录位于data/source-verification.db的source_runs。不同轮次分别记录，不对同一失败无限重试。地方数据不再依赖用户先选一个城市；已按授权支持多地区。
