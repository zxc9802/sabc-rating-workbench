# 访谈与对话附件

新增需求：程序检查访谈收口、上下文有界、聊天上传文档/图片/视频并测量速度。原60例和留出集仍完整保留；可行性客服项目是额外案例。

已实现：模型上下文只发送一次最近16条消息、确认事实与待确认变更分开；保留早期未确认字段；最多12份非旧版本证据，每份6000字，显式报告截取和遗漏。原记录不删除。程序依据既有评级规则判定ready/gathering/paused，不自动批准。

附件：TXT/MD/CSV/JSON/DOCX/XLSX/PPTX/PDF，单文档20MB。图片浏览器和服务端等比压缩。浏览器可解码的视频最长30分钟，均匀抽取6帧并标时间，不上传原视频、不识别音频、不声称全片覆盖。PDF最多50页，其中最多6个扫描页视觉识别；PPTX最多100页文本，嵌入图片和图表不声称已读。识别结果保存为E0待核验项目证据，后续不重传图片。后台持久任务支持恢复，上传显示字节进度与处理阶段。

速度证据：当前配置模型gpt-5.6-luna识别10929字节测试图，用时5.02秒，预算8000、4周正确。此为模型调用补充诊断，不代替网页上传测速。低速网络、长扫描文档、模型拥堵没有无条件时延保证。

待验收：线上文档/图片/视频真实浏览器上传及计时，失败恢复；完整客服项目完成非NR评级；长对话及状态转换网页回归，原QA5-009回归，既有完整主集/留出集/功能检查。
