# 抖音指数浏览器取数

官方入口 https://trendinsight.oceanengine.com/ 本次实际转到抖音创作者中心的抖音指数页面。该页面展示平台升级通知及关键词查询能力。沿用浏览器已可用会话，不读取或保存登录材料。

复测流程：

1. 打开官方入口，关闭升级说明，进入抖音指数关键词查询。
2. 输入实际项目相关关键词并点击搜索。进入结果页后，可修改第一个关键词输入框并按Enter。
3. 必须核对输入框、所有图表标签和地址中的关键词一致。本次中文输入出现“人工智 能”，因此未采纳该组值；短词“AI”在页面规范化为“ai”后，各标签一致。
4. 记录地区、平台、日期起止。读取关键词搜索指数与综合指数的平均值、同比、环比。重复渲染的同一图不重复计数。
5. 若需逐日数据，可进一步核验图表下载功能；本次尚未完成下载，因此不声称已有完整时间序列。
6. 将观察结果填成capture JSON，字段同baidu-browser.md，source_id=douyin，来源为实际creator.douyin.com页面。使用scripts/import_browser_evidence.py导入项目。

本次真实观察：ai，全国，抖音，2026-08-08至2026-09-08。搜索指数平均1855.2万，同比+93.59%、环比+3.40%；综合指数平均817.6万，同比+80.12%、环比+2.49%。原样保留“万”与百分比，不当作人数或交易额。证据编号4fc720a79642479d946c52585e8633ad，独立测试数据库data/source-verification.db，初始待核验E0。

当前为浏览器辅助流程，依赖有效会话与页面结构；不是已接通无人值守API。中文词输入问题需继续回访，不能以ai替代用户实际指定词的结果。
