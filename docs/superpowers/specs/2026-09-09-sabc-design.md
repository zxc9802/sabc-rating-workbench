# SABC 决策工作台设计

用户已确认 Goal v2。交付为本机运行的单公司网页应用，真实公司资料可后补；不得用演示资料冒充真实经营事实。

## 结构

FastAPI 提供本地接口和静态网页，SQLite 保存公司版本、项目、证据、评估快照和取数尝试。评分为无网络依赖的纯函数，输入事实快照、八维建议分和证据，输出可追溯的规则结果。LLM 只提取和解释，建议必须经过结构校验。外部数据作为不可信内容进入模型上下文，不获得工具执行权限。

资料不足输出 NR；已知负面事实才允许低业务分/C。四类模板：商业增长、内部AI提效、战略能力、重资产扩张。证据上限以最弱关键假设决定。新事实复评从可评级门槛重新执行。

## 工作台

石板蓝 #243954、云白 #F4F7FB、正文 #182739、边线 #DCE4EF、强调蓝 #315CF5、验证绿 #157F65。标题用系统中文黑体，正文用 Microsoft YaHei，数字用 Consolas。左侧固定导航；主区域为项目访谈和证据检查；评级报告的八维横条同时标出分值、证据和限制原因。空状态引导建立公司基线和描述项目。未配置模型时明确提示，不伪装智能访谈。

## 取数

14 个渠道分别记录状态。API 优先，正文/导出/浏览器其次。首次失败加最多3次重试，随后进入暂缓队列；完成容易渠道后回访。需要验证码、审批或实名材料时记录依赖，继续独立工作。取数成功必须保存实际证据；只打开官网不算接通。

## 验证

规则边界、全部10类对抗场景、固定事实重复评分、证据去重/过期、来源限制、重试顺序、持久化快照、模型输出校验、导入及网页端到端流程。API真实请求与离线规则测试分开报告。真实案例未提供时不能声称准确性已经验证。
