# SABC Implementation Plan

Goal: 实现已确认的 Goal v2，先接容易渠道，失败首次加3次重试后暂缓并回访。

Architecture: FastAPI + SQLite + 原生网页；评分、取数、模型、存储分别独立。

Tech Stack: Python 3.12, FastAPI, SQLite, HTTPX, HTML/CSS/JavaScript。

- [ ] 规则：tests/test_rating.py 先定义 NR、E0/E1封顶、否决、S门槛、四模板、过期/重复证据测试；运行 pytest 观察失败；实现 sabc/rating.py 后通过。
- [ ] 存储与取数：tests/test_sources.py 验证一个失败源不阻塞后续源、最多4次请求、回访和真实证据入库；实现 sabc/store.py、sabc/sources.py；执行 API 样本并保存报告。
- [ ] 访谈：实现 sabc/llm.py 的兼容模型设置、结构化访谈、评分建议及反方审查；不配置密钥时明确返回配置提示。tests/test_app.py 覆盖模型输出结构校验和项目归属。
- [ ] 应用：sabc/app.py 提供公司版本、项目、上传、证据、评级和报告接口；持久化完整输入快照，复评生成新版本。
- [ ] 界面：web/index.html、web/app.js、web/style.css 构建中文工作台；浏览器验证创建、资料保存、数据检索、访谈、报告及错误处理。
- [ ] 受阻回访：对14渠道记录实际接入结果和限制，完成容易渠道后回访；需要用户材料时继续其他工作。
- [ ] 交付：README.md、启动脚本、docs/validation.md、取数状态清单；运行全部测试与端到端演示。缺失真实模型或公司资料须列为未完成验证。

本轮在当前已授权空目录按顺序实施，避免额外工作树和未经请求的子代理。代码步骤以随实现提交的失败测试为精确验收契约。
