# 地方数据自动采集

## 用户确认的目标补充（2026-09-09）

- 外部数据接入必须使用可由项目后端重复调用的公开接口或爬虫，不使用屏幕快照、截图识别或预先保存的浏览器页面作为取数方式。
- 每轮用户回答后，系统根据当前项目描述和新增信息确定相关查询，实际调用接口或爬虫获取证据，再用于追问或评级；不能仅提供手动采集按钮便视为完成。
- 记录每次请求的来源、查询条件、获取时间、数据自身的统计期间、地域范围及返回限制。新请求取得的历史统计数据仍标明原始年份，不能称为当期数据。
- 失败、无匹配或只有部分预览时明确标注，不以旧快照或虚构内容补位。保存接口响应供审计可以保留，但不能替代本轮取数。
- 保留既有范围与重试规则：持续扩展省市覆盖，跳过需要登录注册的来源；阻塞平台重试3次仍失败则暂缓，先接通其他来源。
- 验收：连续两轮回答产生可追溯的本轮取数记录；用户更换地区或行业后查询随之变化；失败场景不会静默引用旧快照；无外部取数需求的回答明确记录无需查询的原因。

以上为新增实现与验收要求，不表示每轮对话自动取数目前已经全部完成。

项目已支持后台 HTTP 搜索官方目录、检查无条件开放属性，再请求数据预览。每次采集重新请求网站，不依赖浏览器历史快照、登录态或注册账号。

在证据库选择“地方公共数据”，输入以下任一查询，点击“获取并保存证据”：

| 查询 | 实测结果 |
| --- | --- |
| `dazhou/search:人口` | 达州市统计局人口目录，返回11行，接口总数标记30，非全量 |
| `panzhihua/search:常住人口` | 西区统计局常住人口表，返回6行，年份含义需核验 |
| `shandong/search:社会消费品零售总额` | 限额以上零售额统计信息，返回10行，总数标记20，非全量 |
| `shenzhen/29200_00403632` | 按已知目录编号获取公开预览，尚未支持关键词搜索 |
| `fujian/search:森林公园` | 福建省林业局，返回30行，非全量 |
| `suzhou_ah/search:人口` | 安徽宿州2023年每万人口在校学生数，返回6行 |
| `yaan/search:人口` | 区县人口数及自然变动，返回10行 |
| `yibin/search:人口` | 人口普查受教育程度统计，返回11行 |

除深圳外可替换关键词（最多60字）。另支持山东12个地市：zaozhuang、zibo、dongying、yantai、weifang、taian、rizhao、linyi、dezhou、liaocheng、binzhou、heze；格式同上，东营示例为 `dongying/search:生产总值`。全部已取得实际公开记录，可能为区县数据。

读取官方搜索页第一批结果中标题匹配且无条件开放的目录，最多检查3个，跳过个人敏感明细或无可用记录目录；无匹配时明确失败，不保存虚构证据。结果不保证最适用于项目，需要核对地区、行业和统计期间。

后端入口沿用 `POST /api/projects/{项目ID}/sources/local`，JSON 为 `{"query":"dazhou/search:人口"}`。模型的数据请求也支持该格式。

实现位于 `sabc/local_sources.py`。山东使用 `/portal/catalog/index?Q=关键词`；达州、攀枝花使用 `/oportal/catalog/index?Q=关键词`。解析目录后，GET 目录页检查开放属性，POST 目录的 `/getData` 获取实际记录。它们是网站公开使用的接口，未取得长期稳定性的保证。

读取公开预览，最多保留100行（深圳50行），不尝试绕过登录或申请。跳转请求直接暂缓。暂时性连接故障最多重试3次；已有采集器记录成功、失败和原始来源。空值不视为零，更新时间不视为统计期间，证据保持未核验状态。

实测原始结果：`artifacts/local-search-live.json`、`artifacts/shandong-city-live.json`、`artifacts/sichuan-extra-live.json`、`artifacts/yibin-live.json`。103项后端测试通过。当前尚未覆盖全国所有省市；逐省进度见 `docs/national-local-progress.md`。杭州、广州此前的快照仍为历史资料，上海尚未取得可用自动数据。

福建单独适配 `/datadevelop/prod-api/open-portal/catalog/` 下的 `list`、`getCataInfo`、`getCataItem`、`getCataItemData`。仅读取普遍开放目录，不下载依申请文件。现场结果为 `artifacts/fujian-live.json`。
